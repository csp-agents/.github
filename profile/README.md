# csp-agents

CSP(Cloud Service Provider) Agents is a project that explores how cloud service provider agents can be modified for red team purposes like Stage 0 and persistence payloads.

Current public repositories

- [**EvilSSM**](https://github.com/csp-agents/evilssm): modified AWS Systems Manager agent
- [**EvilAzp**](https://github.com/csp-agents/evilazp): modified Azure Devops CI/CD Self-hosted agent
- [**EvilOSConfig**](https://github.com/csp-agents/evilosconfig): modified Google Cloud OS Config agent
